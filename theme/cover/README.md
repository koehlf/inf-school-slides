# Cover photos

Copied from the books' `scripts/<Fach>/pictures/cover/` (and, for Digitale Daten and Programmieren, the cover
images that the scripts keep directly in `pictures/`), flattened into one folder per subject.
Each `SOURCES.md` is the script's own and lists the images in the cover's slot order; its paths are relative to the
script's `pictures/` folder, so here only the file name counts.

- Logik has no cover photos in the books yet.
- Networks: only the colour photos are copied; the slides tint them themselves, so the script's `-gray.png` versions are not needed.
